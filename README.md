# Hospic Website (React + Vite + Tailwind CSS)

## Run it
1. npm install      (only the first time)
2. npm run dev      (then open http://localhost:5173)

## Where to change things
- Text, prices, doctors, FAQs: src/data/siteData.js
- Pictures (online links or offline imports): src/data/images.js
- How a card looks: src/components/cards/
- Order of sections: src/App.jsx
